[이수ON - 웹 화면 버전] 사용법

1) 실행파일 만들기 (최초 1회, 인터넷 필요)
   - 이 폴더의 "EXE만들기_웹UI.bat" 더블클릭
   - 끝나면 dist 폴더에 "이수ON.exe" 가 생깁니다.
   (Python이 설치돼 있어야 합니다. https://www.python.org 에서 설치 시
    "Add Python to PATH" 체크)

2) 사용하기 (인터넷 불필요)
   - "이수ON.exe" 더블클릭 → 작은 '실행 중' 창이 뜨고,
     기본 브라우저에 이수ON 화면이 열립니다.
   - PDF/폴더 선택 → 항목 정리 → [엑셀 파일로 저장]
   - 스캔(이미지) PDF도 내장 OCR로 자동 인식합니다. (인터넷 불필요)
   - 사용이 끝나면 '실행 중' 창을 닫으면 종료됩니다.

* 모든 처리는 이 PC 안에서만 이루어지며 외부로 전송되지 않습니다.
* Python 없이 바로 쓰고 싶으면, exe를 만든 뒤 그 exe만 복사해서 쓰면 됩니다.
