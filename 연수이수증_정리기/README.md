# 연수 이수증 정리기

PDF 이수증에서 **이수번호 · 과정명 · 성명 · 직급 · 근무기관 · 이수시간 · 이수일자 · 이수기관**을
뽑아 **엑셀(.xlsx)** 로 정리합니다. 원하는 항목만 골라서 추출할 수 있습니다.

## 🔒 보안 (가장 중요)
- PDF는 **내 PC(브라우저) 안에서만** 읽힙니다. 내용·결과를 **인터넷으로 전송하지 않습니다.**
- 두 가지 방식 모두 PDF를 외부로 업로드하지 않습니다.

---

## 방법 A. HTML 파일 (권장 · 설치 불필요)

**`연수이수증_정리기.html`** 파일을 PC에 저장하고 **더블클릭**하면 브라우저에서 바로 열립니다.

1. PDF 이수증을 끌어다 놓거나 클릭해서 선택 (여러 개 동시 가능)
2. **엑셀로 추출할 항목** 체크박스로 원하는 열 선택
3. 값이 틀리면 표의 칸을 클릭해 직접 수정
4. **[엑셀 파일로 저장 (.xlsx)]** 클릭 → `연수이수증_정리_날짜.xlsx` 다운로드

> 참고: PDF 해석(pdf.js)과 엑셀 생성(SheetJS) **라이브러리만 최초 1회 인터넷에서** 불러옵니다.
> PDF 내용은 전송되지 않습니다. 라이브러리까지 **완전 오프라인**으로 쓰려면 방법 B(.exe)를 쓰거나,
> 라이브러리를 파일에 내장한 버전을 요청하세요.

### 주요 기능
- **항목 선택 체크박스**: 이수번호/과정명/성명/직급/근무기관/이수시간/이수일자/이수기관
- **두 줄로 나뉜 값 자동 합치기**: 예) 근무기관 `경상남도교육청 경상남도사천교육지원청 문선초등학교`
- **꾸러미(법정의무) 연수 키워드**: 키워드를 입력하면 PDF(이수시간 아래 세부내역 포함)에서 찾아
  **과정명 뒤에 `(키워드)`** 로 붙여 줍니다. 줄바꿈으로 갈라진 단어도 인식합니다.
- **이수기관 자동 추정**: 발급기관장이 도장·이미지라 글자가 없어도 **이수번호 앞부분**으로 기관명을 채웁니다.
  - 예) `경남교연-…` → 경상남도교육청교육연수원, `중앙교육연수원-…` → 중앙교육연수원
  - 「이수기관」 칸에 직접 입력하면 그 값이 우선됩니다.

---

## 방법 B. 설치형 실행파일(.exe) — 완전 오프라인

인터넷 없이 **내 PC에서만** 돌아가는 설치형 프로그램입니다. 창(GUI)이 뜨고, 폴더를 고른 뒤
[정리 시작]을 누르면 그 폴더에 엑셀 파일이 바로 저장됩니다. **방법 A(HTML)와 기능이 동일**합니다:
항목 선택 체크박스, 두 줄 값 합치기, 꾸러미 키워드, 이수번호로 이수기관 자동 추정.

1. `EXE만들기.bat` 더블클릭 → `dist\연수이수증정리기.exe` 생성 (수 분, 최초 1회만)
2. 이후에는 **`연수이수증정리기.exe`만 더블클릭** (인터넷·Python 불필요)
   - 또는 바로 실행하려면 `실행하기.bat` (Python 필요)

> `.exe`를 만드는 과정(`EXE만들기.bat`)에서만 설치용 패키지를 인터넷으로 내려받습니다.
> 만들어진 `.exe`는 완전 오프라인으로 동작하며 PDF 내용을 외부로 전송하지 않습니다.

## 결과 엑셀 보는 법
| 번호 | 이수번호 | 과정명 | 성명 | … | 비고 |
|----|--------|------|----|---|----|

- **비고가 비어 있으면(정상)** 모두 추출된 것입니다.
- **검토필요**가 뜨면 해당 항목이 자동 인식되지 않은 것이니 표에서 직접 확인·수정하세요.

## 스캔본(이미지) PDF
글자를 복사할 수 없는 **스캔 이미지 PDF**는 텍스트 추출이 안 됩니다. 발급받은 이수증은 대부분
텍스트 PDF라 그대로 동작하지만, 스캔본 처리가 필요하면 알려주세요(OCR 추가 가능).
