# 연수 이수증 정리기

PDF 이수증들이 들어있는 폴더를 선택하면 **이수번호 · 이름 · 이수일자**만 뽑아 **엑셀(.xlsx)** 로 정리해 주는 프로그램입니다.

## 🔒 보안 (가장 중요)

- 모든 처리는 **내 PC 안에서만** 이루어집니다.
- 이수증 내용이나 결과를 **인터넷으로 전송하지 않습니다.** (서버/클라우드 전송 없음)
- 인터넷 연결이 끊긴 상태에서도 동작합니다. (단, 최초 1회 설치 때만 인터넷 필요)

---

## 사용 방법

### 방법 1. 바로 실행하기 (Python 설치되어 있는 경우)

1. `실행하기.bat` 더블클릭
2. 처음 한 번은 필요한 구성요소가 자동 설치됩니다.
3. 창이 뜨면 **[폴더 선택]** → 이수증 PDF들이 든 폴더 선택 → **[정리 시작]**
4. 같은 폴더에 `연수이수증_정리_날짜시간.xlsx` 가 만들어집니다.

### 방법 2. 실행파일(.exe) 만들어 쓰기

1. `EXE만들기.bat` 더블클릭 (수 분 소요)
2. 완료되면 `dist` 폴더 안에 **`연수이수증정리기.exe`** 가 생깁니다.
3. 이 **exe 파일 하나만** 복사해 두면, 이후엔 Python 없이 더블클릭으로 바로 실행됩니다.

---

## 결과 엑셀 보는 법

| 번호 | 파일명 | 이수번호 | 이름 | 이수일자 | 비고 |
|----|------|--------|----|--------|----|

- **비고가 비어 있으면** 정상적으로 추출된 것입니다.
- **노란색 행 / 비고에 "검토필요"** 가 있으면 해당 항목이 자동 인식되지 않은 것이니, 원본 PDF를 열어 직접 확인/수정하세요.

---

## 추출 규칙 (양식이 다를 때)

이 프로그램은 다음을 자동으로 찾습니다.

- **이수번호**: `이수번호`/`연수번호` 등의 라벨, 또는 상단의 `제 ○○○ 호` 형태
- **이름**: `성명`/`이름` 라벨 (글자 사이 공백도 인식: `성 명`)
- **이수일자**: `이수일자`/`수료일` 라벨 → 없으면 `연수기간`의 **종료일** → 없으면 하단 **증명/발급 날짜**

기관마다 이수증 양식이 다를 수 있습니다. 인식이 잘 안 되면 `cert_organizer.py` 파일 위쪽의
`NUMBER_LABELS`, `NAME_LABELS`, `DATE_LABELS`, `PERIOD_LABELS` 목록에 해당 양식의 라벨을 추가하면 됩니다.

---

## 스캔본(이미지) PDF 안내

글자를 복사할 수 없는 **스캔 이미지 PDF**는 텍스트 추출이 안 되어 "텍스트 추출 실패(OCR 필요)" 로 표시됩니다.
대부분의 발급 이수증은 텍스트 PDF라 그대로 동작하지만, 스캔본 처리가 필요하면 알려 주세요. (OCR 기능 추가 가능)

---

## 필요 환경

- Windows
- Python 3.9 이상 (방법 2로 exe를 만들면 배포 PC에는 Python 불필요)
