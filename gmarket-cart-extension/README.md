# 장바구니 자동 선택 (지마켓) — 브라우저 확장프로그램

엑셀(.xlsx)에 적어 둔 **구입 물품 목록**과 **상품명이 일치하는 상품만**
지마켓 장바구니에서 자동으로 체크(선택)해 주는 크롬/엣지 확장프로그램입니다.

> ⚠️ 안전을 위해 **상품 "선택(체크)"까지만** 자동으로 하고,
> **최종 결제·주문은 직접** 눌러 주세요.

## 무엇을 하나요

1. 지마켓 **장바구니 페이지**를 엽니다. (사려는 상품들은 이미 담겨 있어야 합니다.)
2. 확장 팝업에서 **구입 물품 엑셀**을 올립니다.
3. **"엑셀 목록대로 선택"** 을 누르면, 장바구니에 담긴 상품 중
   엑셀의 품목명과 이름이 맞는 것만 체크하고, 나머지는 체크를 풉니다(옵션).

## 엑셀 형식

- 첫 번째 시트만 읽습니다.
- **헤더 행을 자동으로 찾습니다.** 맨 위에 제목 줄(예: "6학년 학습 준비물")이 있어도 괜찮습니다.
- 상품명 열 이름으로 `항목` / `상품명` / `품목` / `물품` / `품명` / `제품` / `name` 중 하나를 인식합니다.
- 규격(옵션) 열 이름으로 `규격` / `사양` / `옵션` / `사이즈` / `size` 를 인식하면, **같은 상품의 서로 다른 옵션(예: F3·F4, 화이트·레드)을 구분**해 선택합니다.
- 헤더를 못 찾으면 **첫 번째 열**을 상품명으로 가정합니다.

예시(실제 준비물 엑셀 형태):

| 연번 | 항목 | 규격 | 단위 | 수량 | 단가 | 합 |
|---|---|---|---|---|---|---|
| 1 | 코바늘 키링 뜨개 세트 | 8개 세트 |  | 3 | 19200 | 57600 |
| 2 | 스카치 포장용 테이프 | 48mmX50m, 투명 |  | 3 | 2260 | 6780 |
| 4 | 배송비 |  |  | 3 | 3000 | 9000 |

### 배송비는 자동 제외

`배송비` · `택배비` · `종이액자 배송비` 처럼 이름에 **배송비/택배비**가 들어간 행은
목록에서 자동으로 빠집니다(선택 대상이 아님). 몇 개를 제외했는지 팝업에 표시됩니다.

## 매칭 규칙 (중요)

- **항목(상품명)의 모든 단어**가 장바구니 상품명 안에 들어있으면 그 상품을 선택합니다.
  엑셀 항목이 쇼핑몰 상품 제목과 비슷할수록 정확합니다.
- 같은 항목에 여러 상품이 걸리고 **규격**이 적혀 있으면, 규격 단어가 들어간 상품으로 좁혀 선택합니다.
  (예: 항목 "일본 두방지" + 규격 "F4" → 장바구니의 F4 상품만)
- 장바구니에서 못 찾은 물품은 실행 후 팝업에 목록으로 보여 줍니다.

## 설치 방법 (개발자 모드 로드)

1. 크롬 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`).
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드** 를 누르고, 이 `gmarket-cart-extension` 폴더를 선택합니다.
4. 지마켓 장바구니를 연 뒤, 툴바의 확장 아이콘을 눌러 사용합니다.

## 매칭 방법

- **부분 일치(권장):** 장바구니 상품명 안에 엑셀 품목명이 포함되면 체크.
  (장바구니 상품명이 길고 자세해서, 짧은 키워드로 적어도 잘 잡힙니다.)
- **정확히 일치:** 공백을 뺀 이름이 완전히 같을 때만 체크.

## 잘 안 될 때

1. 먼저 **"장바구니 상품 읽기"** 버튼을 눌러 보세요.
   - 상품이 **0개**로 나오면, 장바구니 페이지가 맞는지 확인하세요.
   - 그래도 0개면 지마켓 화면 구조가 바뀐 것입니다 → 아래 2번.
2. `content.js` 맨 위의 `SELECTORS` 를 실제 화면에 맞게 수정합니다.
   - F12(개발자도구)로 상품명 링크의 `href`나 class, 체크박스의 class를 확인한 뒤
     `productHref`, `itemNameOverride`, `itemRowOverride` 에 넣어 주세요.
3. 저장 후 `chrome://extensions` 에서 이 확장의 **새로고침** 버튼을 누릅니다.

## 다른 쇼핑몰(11번가·쿠팡·옥션 등)

지금은 **지마켓** 전용입니다. 다른 몰은 장바구니 HTML 구조가 달라
각 몰별로 `SELECTORS`(또는 별도 content 스크립트)를 추가해야 합니다.
요청하시면 몰별로 확장할 수 있습니다.

## 한계 / 주의

- 쇼핑몰이 화면을 개편하면 선택 로직이 깨질 수 있습니다(위 "잘 안 될 때" 참고).
- 수량 자동 변경은 아직 없습니다. 현재는 **체크(선택)만** 합니다.
- 자동화에 대한 각 쇼핑몰 이용약관을 확인하고, 개인용 보조 용도로 사용하세요.
