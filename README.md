# 공사 사진대지 생성기

사진을 끌어다 놓으면 **공사 전·중·후**로 정리해서 **엑셀(.xlsx)** 또는 **한글·워드(.doc)** 문서로 만들어 주는 웹페이지입니다. 설치 없이 `index.html` 파일 하나만 있으면 동작하며, 인터넷이 없어도 쓸 수 있습니다(엑셀 모듈 내장).

## 사용 방법

1. `index.html` 을 **크롬·엣지 등 브라우저에서 엽니다** (파일을 더블클릭).
2. 맨 위 **공사명** 을 입력합니다. (문서 모든 페이지 상단에 공통으로 들어갑니다.)
3. **공사 전 / 공사 중 / 공사 후** 칸에 사진을 **끌어다 놓거나** `+ 사진 선택` 으로 추가합니다. (여러 장 한 번에 가능)
4. 각 사진 아래 칸에 **설명** 을 적습니다. (사진 아래에 그대로 들어갑니다.)
5. 아래에서 형식을 고르고 **문서 생성** 을 누릅니다.

## 만들 수 있는 문서

| 형식 | 설명 |
|------|------|
| **엑셀 (.xlsx)** | 공사 전·중·후가 **시트별로 자동 분리**되고, 각 시트에 공사명과 사진이 들어갑니다. |
| **한글·워드 (.doc)** | **한글(HWP)·MS워드**에서 바로 열립니다. 한 페이지에 사진 2개. |
| **인쇄 / PDF** | `인쇄 미리보기` → 인쇄하거나 "PDF로 저장" 하면 됩니다. |

## 출력 양식

- 맨 상단: **공사명** (공통)
- 사진: **한 페이지에 2개**, 칸 크기에 맞춰 자동으로 들어감
- 사진 아래: **설명** ( `[공사 전]` 등 단계 표시 + 입력한 설명 )

## 참고

- 사진은 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.
- 한글(HWP) 파일이 꼭 필요하면 **한글·워드(.doc)** 로 만든 뒤 한글에서 열어 저장하거나, **인쇄/PDF** 로 만든 PDF를 한글 문서에 넣으면 됩니다.
