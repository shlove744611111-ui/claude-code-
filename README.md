# 공사 사진대지 생성기

사진을 끌어다 놓으면 **공사 전·중·후**로 정리해서 **엑셀(.xlsx)** 또는 **인쇄/PDF** 로 만들어 주는 웹페이지입니다. 설치 없이 `index.html` 파일 하나만 있으면 동작하며, 인터넷이 없어도 쓸 수 있습니다(엑셀 모듈 내장).

## 사용 방법

1. `index.html` 을 **크롬·엣지 등 브라우저에서 엽니다** (파일을 더블클릭).
2. 맨 위 **공사명** 을 입력합니다. (문서 모든 페이지 상단에 공통으로 들어갑니다.)
3. **공사 전 / 공사 중 / 공사 후** 칸에 사진을 **끌어다 놓거나** `+ 사진 선택` 으로 추가합니다. (여러 장 한 번에 가능)
4. 각 사진 아래 칸에 **설명** 을 적습니다. (사진 아래에 그대로 들어갑니다.)
5. 아래에서 형식을 고르고 **문서 생성** 을 누릅니다.

## 만들 수 있는 문서

| 형식 | 설명 |
|------|------|
| **엑셀 (.xlsx)** | 공사 전·중·후가 **시트별로 자동 분리**되고, 각 시트에 공사명이 들어갑니다. 사진은 **셀 크기에 꽉 맞게**(여백·왜곡 없이) 삽입됩니다. |
| **PDF 파일 (.pdf)** | **한 페이지에 사진 2개**로 PDF 파일이 바로 저장됩니다. (한글도 깨지지 않음) |

`문서 생성` 옆의 **🖨 인쇄** 버튼을 누르면 파일을 만들지 않고 바로 프린터로 인쇄(또는 인쇄 창에서 PDF 저장)할 수 있습니다.

## 출력 양식

- 맨 상단: **공사명** (공통)
- 사진: 칸 크기에 꽉 맞게 자동 삽입 (PDF·인쇄는 한 페이지에 2개)
- 사진 아래: **설명** ( `[공사 전]` 등 단계 표시 + 입력한 설명 )

## 다른 웹사이트(코덱스 등)에 연결하기

`photo-sheet.html` 한 파일만 내 사이트 폴더에 넣으면 됩니다. (라이브러리가 전부 들어 있어 추가 파일이 필요 없습니다.)

**① 버튼/링크로 열기** — 가장 간단하고 어디서나 동작합니다.

```html
<a href="photo-sheet.html" target="_blank" rel="noopener">공사 사진대지 만들기</a>
```

**② 페이지 안에 끼워넣기(iframe)**

```html
<iframe src="photo-sheet.html" style="width:100%;height:860px;border:0"></iframe>
```

`example.html` 을 열어 보면 두 방법이 실제로 동작하는 모습을 볼 수 있습니다. 파일 저장·인쇄는 사이트를 인터넷 주소(http/https)로 올렸을 때 가장 안정적입니다.

## 참고

- 사진은 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.
- **휴대폰 사진의 회전 방향(EXIF)** 을 자동으로 바로잡아 엑셀에서 거꾸로/옆으로 나오지 않습니다.
- 긴 변 1600px로 자동 축소해 파일 용량을 줄입니다.
