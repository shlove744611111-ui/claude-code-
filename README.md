# 공사 사진대지 생성기

사진을 넣고 **레이아웃을 고르면 보이는 그대로** 공사 사진대지를 **엑셀(.xlsx)** 또는 **PDF** 로 만들어 주는 웹페이지입니다. 설치 없이 `index.html`(또는 `photo-sheet.html`) 파일 하나만 있으면 동작하며, 인터넷이 없어도 쓸 수 있습니다(라이브러리 내장).

## 사용 방법

1. 파일을 **크롬·엣지 등 브라우저에서 엽니다**.
2. 맨 위 **공사명** 을 입력합니다. (문서 모든 페이지 상단에 공통으로 들어갑니다.)
3. **레이아웃 블록**에서 배치를 정합니다.
4. **공사 전 / 공사 중 / 공사 후** 구역에 사진을 **끌어다 놓거나** `+ 사진 추가` 로 넣습니다.
5. 각 사진 아래에 **설명** 을 적습니다.
6. 형식(엑셀/PDF)을 고르고 **문서 생성**, 또는 **🖨 인쇄** 를 누릅니다.

## 레이아웃 블록 (편집 화면 = 결과물, WYSIWYG)

| 항목 | 설명 |
|------|------|
| **한 줄 사진 수** | 1 / 2 / 3 / 4 장 — 한 줄에 들어가는 칸 수가 바뀌며 칸이 자동 배치됩니다. |
| **사진 모양** | 가로(4:3) / 세로(3:4) / 정사각 / 원본 — 칸의 비율을 정합니다. |
| **사진 크기** | 칸(=사진) 크기를 30~100%로 조절합니다. |
| **쪽 나눔** | `이어서` 또는 `구역마다 새 쪽`(전·중·후를 페이지마다 나눔). |

## 사진 칸별 기능 (사진에 마우스를 올리면 버튼이 나옵니다)

- **⟳ 회전** : 누를 때마다 오른쪽으로 90° 회전 (저장 시에도 그대로 적용)
- **바꾸기** : 그 칸의 사진을 다른 파일로 교체
- **꽉** (꽉 채우기) : 사진을 확대해 칸을 꽉 채움(잘리는 부분 생김) → 사진을 **드래그**해 보이는 위치를 맞출 수 있음
- **전체** (전체 보기) : 사진 전체가 잘리지 않게 축소해서 칸에 넣음
- **↑ ↓** : 순서 바꾸기 · **전/중/후** : 다른 구역으로 이동 · **✕** : 삭제

## 만들 수 있는 문서

| 형식 | 설명 |
|------|------|
| **엑셀 (.xlsx)** | 공사 전·중·후가 **시트별로 자동 분리**됩니다. 선택한 레이아웃(칸 수·모양·크기)대로 사진이 들어갑니다. |
| **PDF 파일 (.pdf)** | 편집 화면 그대로 A4로 저장됩니다. (한글도 깨지지 않음) |

`🖨 인쇄` 버튼은 파일을 만들지 않고 바로 프린터로 인쇄(또는 인쇄 창에서 PDF 저장)합니다.

## 다른 웹사이트(코덱스 등)에 연결하기

`photo-sheet.html` 한 파일만 내 사이트 폴더에 넣으면 됩니다. (추가 파일 불필요)

```html
<!-- ① 버튼/링크로 열기 -->
<a href="photo-sheet.html" target="_blank" rel="noopener">공사 사진대지 만들기</a>

<!-- ② 페이지 안에 끼워넣기 -->
<iframe src="photo-sheet.html" style="width:100%;height:900px;border:0"></iframe>
```

`example.html` 을 열면 두 방법이 실제로 동작하는 모습을 볼 수 있습니다.

## 참고

- 사진은 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.
- **휴대폰 사진의 회전 방향(EXIF)** 을 자동으로 바로잡습니다.
- 긴 변 1600px로 자동 축소해 파일 용량을 줄입니다.
- 파일 저장·인쇄는 사이트를 인터넷 주소(http/https)로 올렸을 때 가장 안정적입니다.
